# avatier-social-assets

Public image host for Avatier social posts published through Pressmaster.

Pressmaster's media importer only accepts a **public HTTPS URL** (no filesystem paths, no
inline bytes), so rendered post cards are committed here and referenced by their
`raw.githubusercontent.com` URL.

Layout: `<YYYY-MM-DD>-<slug>/card-<aspect>.png`

Aspects: `4x5` (1080x1350, LinkedIn / Instagram / Threads) - `1x1` (1080x1080, Instagram alt)
- `16x9` (1600x900, X / Bluesky / Facebook).

Images only. No credentials, no drafts, no analytics.
